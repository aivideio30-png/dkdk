# Particle Arcana (Minecraft 26.3 / Fabric)

모델·텍스처 없이 삼각함수 + 벡터 + 파티클만으로 구현한 능력자 모드. 서버 로직 + 서버 발송 파티클이라 리소스팩 불필요.

## 조작
| 아이템(주손) | 우클릭 효과 |
|---|---|
| 모든 검 | 곡선 초승달 검기 + 이중 나선 궤적 (쿨 0.75초) |
| 자수정 조각 | 조준 지점의 블록/몬스터를 띄워 가속 회전 → 90틱 후 자동 발사, 회전 중 재우클릭 시 즉시 발사 (쿨 5초) |
| 시계 | 반경 14칸 시간 정지: 몬스터/투사체 정지, 받은 피해 저장 → 해제 시 x1.5 + 4 폭발 (지속 5초, 쿨 20초) |

## 빌드 (JDK 25 + Gradle 9.6 필요)
    gradle wrapper --gradle-version 9.6.0
    ./gradlew build
결과물: build/libs/particle-arcana-1.0.0.jar → mods 폴더에 Fabric API(0.161.0+26.3)와 함께 넣기.
